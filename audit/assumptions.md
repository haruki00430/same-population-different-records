# Assumptions fixed before inspecting simulation results

1. All patient states are independent across patients. No empirical data or downloaded datasets enter any calculation. Literature is used for context only.
2. Main paired experiments use common uniform recording propensities. At equal recording parameters, records are identical. This is a counterfactual coupling, not a claim that repeated chart abstraction is deterministic. Independent re-recording is a sensitivity analysis. Coupling affects replicate probabilities, not marginal expectations.
3. Architectures A and C use exact multinomial sufficient counts of latent and recorded patient categories. These are distributionally identical to individual Bernoulli draws. Patient-level paired views are also implemented and tested.
4. For C, true action is zero outside true eligibility; numerator specificity is one. Eligibility and action recording errors are conditionally independent. The expected ratio is conditional on a nonempty recorded denominator. Uniform denominator loss alone cancels if its false-positive rate is zero; this is a negative control, not an omitted result.
5. Clinical improvement in B means multiplying each patient's event probability by (1-g). In C it means increasing completion by a relative factor (1+g); main q=0.75 gives 0.825 and 0.9. These are explicit extensions needed for the requested three-panel improvement figure. Module 4 changes clinical outcomes/actions and is not an identical-outcome null experiment.
6. B1 applies known latent coefficients to recorded covariates, so baseline O/E need not equal one. B2 is trained on one independent synthetic cohort of 250,000 patients with baseline recording, then frozen. Its simulation uncertainty is conditional on that development fit. No refitting at B. For bias on the raw O/E scale, the true reference is observed outcomes divided by expected risks using complete latent covariates with the known coefficients; its population change is -g. Relative comparisons are also reported separately.
7. Independent repeated cohorts use fresh clinical and recording draws in A and B. Main repeated-cohort curves use g=0; improvement experiments use coupled potential outcomes/actions on the same covariate population.
8. Relative changes are raw measure changes: negative improves A/B, positive improves C. Practical cutoffs are strict 5% and 10%; masking is |relative change| <=1%. Reversal is any change in the adverse direction when g>0, and is descriptive direction probability when g=0. Undefined ratios are reported, never imputed.
9. Tipping points are population-expectation roots, not roots of average replicate ratios. Exact equality masks; a strict change beyond the root reverses. A root outside the allowed domain is reported as unattainable.
10. SPC limits are estimated once using all 24 baseline months, never recomputed. Primary rule uses eight strictly same-side points; equality resets runs. Runs restart at month 25. Lag is first signal month minus 25, conditional on detection; no signal is censored. Rule probabilities are separate, not combined. No-change controls use the identical monitoring procedure.
11. Main SPC endpoints are 0.80, 0.82, 0.85, 0.90, 0.95, all examined for abrupt and linear changes. Figure 4 uses the first replicate at the prespecified 0.90 abrupt endpoint, whether or not it signals.
12. Sensitivity analyses are one-factor-at-a-time, not a full factorial. A and C retain full response grids. B computational sensitivities use c_B=0.50,0.70,0.90,1.00, 10,000 replicates each. Baseline B2 coefficients remain those trained at c=0.70. Correlated B errors mix a patient-shared uniform across comorbidities (probability 0.5) with independent uniforms. Severity-dependent capture changes sensitivity by +0.10 for C3-positive patients and -0.10 otherwise, clipped to [0,1].
13. Formal signal/noise reliability is a supplementary hierarchy: true event risks uniform on [0.03,0.07] across units. Reliability = Var(p Se)/(Var(p Se)+E[p Se(1-p Se)]/N). This supplements, rather than equates reliability with, precision in the homogeneous main experiments.
14. Nominal 95% intervals for A change use ordinary paired or independent Bernoulli sampling variance, ignoring recording drift. Empirical replicate intervals are sampling distributions, not confidence intervals on the Monte Carlo mean. MCSE accompanies probabilities; Wilson bounds address boundary estimates.
15. GO criterion is prespecified operationally as >=5% apparent relative change or masking/reversal of 10% improvement for <=10 percentage points of capture perturbation in at least one architecture. This is a methodological relevance criterion, not an empirically justified plausibility threshold. Moderate: effects require larger changes; weak: no meaningful effect over the supplied grids. All cells remain available.
16. Main result cells use R=10,000. Smoke runs validate implementation only. Figures and manuscripts are generated only after the full run and audit. Seeds are keyed to scenario labels with SHA-256, independent of execution order. Common random numbers across curve cells induce correlation; cells are not independent experiments.
17. Protocol is prepared before execution but is not registered; its timestamp and config hash are recorded. Bibliographic verification does not establish empirical parameter calibration. Journal limits that cannot be verified remain a submission check.
