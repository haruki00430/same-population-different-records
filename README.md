## Reproduce

Python 3.12 is recommended. From this directory, in a terminal with Python available:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m pytest -q tests/test_core.py tests/test_smoke.py
.venv\Scripts\python.exe scripts/run_all.py --stage all
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe scripts/build_manuscript.py
```

On Linux/macOS substitute `.venv/bin/python` for `.venv\Scripts\python.exe`. After dependencies are installed, the full scientific pipeline including verification and manuscript outputs is one command:

```text
python scripts/reproduce.py
```

To rebuild figures/tables/audit and manuscript from saved summaries without rerunning simulations:

```text
python scripts/run_all.py --stage build
python scripts/build_manuscript.py
```

Stages `main`, `sensitivity` and `spc` are also available. Main fits and freezes the development model. Sensitivity reuses saved coefficients. To change parameters, edit only `config/simulation_config.yaml`, then rerun **all** stages. The manuscript generator assumes the supplied study design; review wording if changing that design. Full runs use 10,000 replicates per cell; no silent reduction occurs. The small smoke test writes no full-run results.

## Design and interpretation

Four modules: paired identical patients, independent repeated cohorts, 48-month SPC, and true clinical improvement with simultaneous record drift. Three measure architectures: safety event rates, O/E with two fixed risk models, and process completion. Main null paired experiments change recording alone. Module 4 explicitly changes potential outcomes/actions and is kept separate.

A/C use exact latent/recorded multinomial counts, equivalent in distribution to simulating every Bernoulli patient individually. B simulates individual covariates/outcomes in memory-limited batches. Common recording uniforms couple paired records; independent re-recording and independent cohorts are separate sensitivity/design conditions. An immutable patient-level implementation is unit-tested and a patient-level illustration is saved. Model development uses a separate random stream and 250,000 synthetic patients. Quadrature calibrates the risk intercept without empirical data.

For A/B negative relative changes imply improvement; for C positive changes imply improvement. `mean_RC` is the mean of replicate ratios; `ratio_of_means_RC` and `expected_RC` are different estimands and are labelled separately. `bias` subtracts latent clinical change. B bias uses O/E units and complete-covariate reference change -g; B1 baseline need not be calibrated. All O/E analyses condition on frozen development coefficients.

Practical inference probabilities use strict >5% and >10% relative change. `masked` is |RC|<=1%. `direction_reversal` describes true reversal only for g>0; at g=0 it is merely adverse-direction probability. Ratios with zero baseline or recorded denominator are undefined and their counts are retained. Probabilities condition on valid ratios. MCSE uses the valid count, with Wilson bounds when estimates are at 0 or 1.

`delta_q025/q975` and `RC_q025/q975` describe empirical sampling distributions, not CIs around simulation means. `delta_mcse` is uncertainty of the Monte Carlo mean. A nominal 95% change intervals use paired/independent Bernoulli sampling variance, deliberately ignoring record drift; these support the precision analysis. Formal signal/noise reliability is evaluated in a separate explicitly heterogeneous hierarchy.

SPC uses baseline-estimated frozen limits, restarts the run rule at month 25, and evaluates each rule separately. First-signal and lag summaries condition on detection; nondetections and restricted lag are also reported. Main and sensitivity sample sizes are distinguishable by `n` in the common SPC table. Chart signals reflect observed-process change and are not automatically evidence of changed care.

## Output layout

`src/`: models, recording, measures, simulations, SPC, reporting. `tests/`: identity, analytical expectations, reproducibility, risk integration, SPC logic and saved-result checks. `results/main/`: main summaries and fixed-seed illustrative patient/time-series data. `results/sensitivity/`: separate sensitivity summaries. `tables/`: two primary tables and full supplementary tables. `figures/`: four main and five supplementary figures in PNG, SVG and vector PDF. `manuscript/`: draft, abstract, introduction, methods, results, discussion, supplement, cover letter, protocol and citation records. `audit/`: assumptions, hashes, logs, numerical audit and deliverable inventory.

No replicate-level B patients are saved; deterministic seeds and code regenerate them. All parameter-cell summaries are retained. Figure 2/4 illustrations use a fixed seed/first replicate and are not selected for dramatic effects. Output CSVs are plain machine-readable text, not proprietary spreadsheets.

## Limits and author actions

The parameters illustrate mechanisms and are not empirical universal values. A successful stress-test study does not establish the prevalence of these problems in healthcare systems. The project is a complete computational study and manuscript **draft**, not a submitted paper. Authors must supply identities, affiliations and declarations, verify current journal requirements, and review the correction/metadata items in `manuscript/unverified_citations.md`. The protocol was prepared before the run but was not registered. Publication novelty and acceptance require editorial judgement.
